# Kavanah Release Checklist

## Required before TestFlight

- Configure `OPENAI_API_KEY` only on the server and deploy `api/assistant.js`.
- Set `EXPO_PUBLIC_ASSISTANT_API_URL` in the EAS production environment.
- Add the EAS project ID generated by `eas init` to the Expo configuration.
- Verify Apple signing, notification entitlement, bundle ownership, and App Store Connect access.
- Obtain rabbinic approval for exact Hebrew prayer text, content scope, tradition, and source edition. Review translations, transliterations, licenses, and ritual descriptions separately with qualified language/content reviewers.
- Replace unofficial translation endpoints with a licensed production translation service or reviewed static translations.
- Complete device tests for denied permissions, offline behavior, VoiceOver, Dynamic Type, right-to-left text, and reduced motion.
- Add production crash reporting that excludes prayer questions, precise location, and personal text.
- Run internal TestFlight testing, then external testing across supported iPhone and iPad sizes.

## Required before App Review

- Publish the privacy policy and terms at stable public URLs and enter them in App Store Connect.
- Complete App Privacy labels, including location, user content sent to the assistant, identifiers used for abuse prevention, and third-party processing.
- Prepare the app name, subtitle, description, keywords, support URL, review notes, screenshots, and age rating.
- Explain the optional prayer assistant, location calculation, and notification flow in App Review notes.
- Confirm that all core features remain usable without sign-in, location, notifications, biometrics, or assistant consent.
- Confirm production rate limiting uses shared durable storage or infrastructure-level enforcement rather than process memory alone.
